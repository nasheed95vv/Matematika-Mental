## Общие положения

Приложение «Ментальная математика» (далее — «Приложение») разработано с
приоритетом на приватность пользователя. Приложение **полностью работает
офлайн** и не имеет разрешения на доступ к интернету (`INTERNET`) в принципе —
это означает, что Приложение технически не может передавать какие-либо данные
на сторонние серверы, поскольку у него нет возможности установить сетевое
соединение.

## Какие данные собирает Приложение

Приложение хранит следующие данные **исключительно локально, на устройстве
пользователя**, в зашифрованном виде:

- игровой прогресс (опыт, монеты, разблокированные уровни и достижения);
- статистика тренировок (количество решённых примеров, точность, история
  сессий);
- пользовательские настройки (звук, вибрация, тема оформления, размер
  текста, время ежедневного напоминания).

Приложение **не собирает**:
- персональные данные (имя, email, номер телефона, геолокацию);
- данные об устройстве, передаваемые за пределы устройства;
- рекламные идентификаторы;
- какие-либо данные для аналитики или трекинга.

## Как защищены данные

Все локальные данные хранятся в зашифрованном виде:
- настройки и игровой прогресс — через `EncryptedSharedPreferences`
  (AES-256), ключ шифрования защищён Android Keystore устройства;
- история тренировок — в базе данных, зашифрованной по алгоритму SQLCipher
  (AES-256).

Ключи шифрования генерируются случайным образом при первой установке,
уникальны для каждого устройства и никогда не покидают устройство.

## Разрешения приложения

Приложение запрашивает только одно разрешение:
- **Уведомления** (`POST_NOTIFICATIONS`, только Android 13+) — используется
  исключительно для показа локального ежедневного напоминания
  потренироваться, если пользователь включил эту функцию в настройках.
  Уведомления формируются полностью на устройстве, без участия сервера.

## Передача данных третьим лицам

Приложение не передаёт никакие данные третьим лицам, поскольку не имеет
технической возможности выхода в сеть.

## Хранение и удаление данных

Все данные удаляются автоматически при удалении Приложения с устройства.
Пользователь также может очистить данные вручную через кнопку "Сбросить
прогресс" в настройках Приложения, либо через системные настройки Android
(Настройки → Приложения → Ментальная математика → Хранилище → Очистить
данные).

## Дети

Приложение не собирает персональные данные ни у кого, включая детей, и
подходит для семейного использования.

## Изменения в политике конфиденциальности

При внесении изменений в данную политику обновлённая версия будет
опубликована по тому же адресу с указанием новой даты вступления в силу.
